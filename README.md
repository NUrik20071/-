# WaveLock

Android live wallpaper с анимированными волнами и реакцией на касания.

## Возможности
- Три визуальных стиля: океан, спокойная вода и абстракция.
- Настройки скорости, высоты волн и свечения.
- Рябь появляется в точке касания, если Android/прошивка передаёт события живым обоям.
- Настройки и рендеринг на Android через Jetpack Compose и WallpaperService.

## Сборка APK
Сборка выполняется автоматически через GitHub Actions при каждом push в `main`.

1. Открой вкладку **Actions** репозитория.
2. Выбери workflow **Build Android APK**.
3. Открой успешный запуск.
4. Внизу страницы скачай артефакт **WaveLock-debug-apk**.
5. Распакуй ZIP и установи `app-debug.apk` на Android.

Требования: JDK 17, Gradle 8.9, Android Gradle Plugin 8.7.3, Android SDK Platform 35.

## Установка
1. Установи APK.
2. Открой WaveLock, настрой стиль и параметры.
3. Нажми «Применить живые обои».
4. В системном окне выбери экран блокировки, если прошивка предлагает такой вариант.

## Ограничения Android
Приложение не заменяет системный экран блокировки и не перехватывает PIN/пароль. Возможность установки живых обоев на экран блокировки и доставка touch-событий зависят от версии Android и прошивки производителя. Это нужно проверить на конкретном устройстве.
